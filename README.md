One line of office comedy, at most 200 characters. The program writes the joke to `/output/entry.txt` and the judge compares entries head to head.

## The line

> My calendar blocked 'focus time' from 2 to 4. At 2:03, my manager booked over it: 'quick chat about focus time.'

(112 characters — one line, one office detail, the payoff lands in the last few words.)

## Run

```sh
node main.ts
```

Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`).
